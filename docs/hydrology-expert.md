# 水文专家：从哪里开始

在新对话选择“水文专家”，用日常语言描述你想做的事情即可。它会帮助你逐步准备研究所需信息，并使用水文工具执行任务。以下是对话示例，不是已完成的实验结果。

## 第一次使用

可以发送：“我第一次用，你能帮我做些什么？”水文专家会简短介绍数据准备、模型率定、深度学习训练、绘图与指标四类能力，给出可以继续发送的例句，再问你是否已有数据。这类介绍不启动科学计算，也不要求填写工具参数。

已有明确目标时可以直接发送：“帮我检查我的降雨、蒸散发和径流数据”，或“用我的数据快速率定新安江模型，并画出实测与模拟过程线”。执行前会核实当前安装实际支持的模型和读取方式。

## 已有数据

先说明你想研究什么，以及自己选择的数据文件夹。助手会按当前任务分步核对流域、日期、变量和单位；率定、验证时期及预热长度在需要时再确认。已经说明的信息会继续使用，不需要每轮重填。不确定文件格式时可以先问“我的数据要整理成什么样，能给个示例吗？”

没有数据时，可以先了解准备清单，或明确选择合成数据演示。合成数据只用于理解流程，不作为真实流域研究的输入。

## 运行与结果

执行中会说明当前在检查数据、率定、训练还是评估；后台句柄仍需等待最终结果。完成后优先给出关键发现、实际指标、图表和成果引用，并结合你的目标建议一到两个下一步，例如检查误差、比较实验或调整率定方案。建议新的计算方案后，等待你的选择。

遇到错误时，会解释阻塞位置、已保留的结果和一个最小的解决动作。水文工具或后台任务失败后停止新科学任务；你补充信息或发出新指令后，可以在原研究中继续。算法停止、计算完成和预测质量分别报告。
