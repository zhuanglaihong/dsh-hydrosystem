# 工作台布局与渐进式信息展示

2026-11-09，按已确认的交互概念调整同仓库 packages/hydro-workspace。交付候选为 @iheadwater/dsh-hydro-workspace@0.1.0-alpha.6，基础能力保持 alpha.8。基础检查点仍为 302160d；UI 改动在 codex/hydro-workspace，未提交或推送。

## 界面行为

管理导航移到左侧，包括研究概览、数据与模型、实验、图表与成果、研究记录和环境与算力。研究助手使用中央主区域，继续渲染 DSH 原生 Conversation；切换管理页只隐藏该对话，不卸载同一会话的输入组件。文件、产物与实验复用 DSH 的 Modal，临时查看不改变对话宽度；执行记录在底部按需展开。窄屏将研究导航收进同一原生 Modal，Escape、遮罩和关闭按钮沿用宿主行为。

画布节点保留实际任务名称、时间和状态，隐藏内部操作名与不透明引用。数据页显示数据集、流域、率定和验证时段；原始声明、目录、配置和任务记录默认折叠。任务页的率定目标按记录原值展示，标签明确为率定目标，不当作验证指标。产物使用可读类别名称，PNG 直接预览，JSON 的原始内容按需展开，原有目录限制、内容哈希与大小校验继续生效。

“在研究对话中分析”保留当前实验选择，用户可复制实验上下文并粘贴到原生输入框，确认后发送；不自动注入模型请求、变更研究绑定或执行科学任务。研究记录页展示包含同一科学证据引用的原对话，尚无独立笔记编辑器。环境页明确要求通过实际环境工具确认就绪状态，不根据安装位置宣称环境可用。交互式终端和任意目录文件管理仍未接入。

## 验证方法

复用已确认的公开入口：真实 Next 客户端、实际安装 tarball、只读 HTTP 与 Session Projection。先在旧 alpha.3 上观察“研究管理”导航缺失的失败，再实现新布局。桌面检查另发现位置文案仍写“上方”，以相同客户端测试复现并改为与位置无关的引导。没有修改测试来绕过原有数据保护或错误处理要求。

pnpm run check 覆盖类型、构建和 4 项源／HTTP／Projection 测试；最终包通过 node --test tests/workspace-browser.test.mjs，在 .omx/workspace-alpha6-final 隔离 Profile 运行目标 Next 的实际 Host 和 Client。用空的隔离会话输入未发送的测试草稿，验证文件／产物／实验弹窗及管理页往返后仍保留草稿，随后清空该测试草稿。验收不向模型发送消息。

浏览器检查左侧导航位置、默认没有可见原始 JSON／内部操作名、任务复现信息默认折叠且可展开、实验上下文显式确认、约 976 像素主对话、弹窗不挤压对话、真实产物校验预览、底部记录开关，以及 1024／390 像素下的布局和窄屏导航。包的更新、正式桌面文件比对及重载另记录在 .omx/workspace-alpha6-install.json 与 .omx/workspace-alpha6-audit.json。

开发过程中同一 alpha.4 文件路径被重新打包，桌面 pnpm 复用了旧内容；逐文件校验准确报出 lib/client.js 不匹配。最终使用新的 alpha.6 版本号和工件路径安装，不删除共享缓存。后续已安装工件必须使用新版本号更新，不能用同一版本覆盖后仅凭安装成功判断加载完成。

本轮仅改 UI、文案、发行声明和验收，不修改科学执行器、环境、上游包或已有研究。未重复率定、训练和科学集成回归，未做 Mac 真机验收；原科学闭环验证保留在此前的阶段记录。
