# alpha.8：水文专家使用引导

本次仅修改水文专家 description 与 persona 提示词，以及版本和说明文档。科学执行器、工具 schema、运行时、worker、环境和 Study 不变；与 alpha.7 的实际 tarball 比较，只有 package.json、cordis.patch.yml、README.md 三个文件不同。

## 对话设计

初次打招呼或询问用途时，介绍数据准备、模型率定、深度学习训练、绘图与指标，提供两条可直接发送的例句，最后只问一个起步问题；这类介绍不触发环境查询或科学计算。明确任务直接推进，缺少输入时每次只询问最关键的一到两项，已提供的信息复用。执行中说明当前步骤，结果优先给关键发现、图表与证据，后续方案等待用户选择。阻塞时说明位置、保留结果和最小解决动作，沿用既有失败停止规则。

人工检查覆盖初次使用、明确任务且输入不足、已有研究继续、任务完成、环境未就绪及工具错误六种场景。示例与说明见[水文专家使用引导](../hydrology-expert.md)。本轮没有调用付费模型，不把提示词审阅视为模型输出验收。
