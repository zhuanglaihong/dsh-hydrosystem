# 水文研究工作空间概念

本目录保存用户确认可作为初步方向的概念材料，属于第三阶段设计，不是已连接 DSH 的界面。所有实验与指标均为示意。

[界面截图](hydro-workspace-concept.png)展示对话为主的状态；[交互概念原稿](hydro-research-workspace.concept.html)可在支持该片段运行环境的预览中讨论布局。原稿不是独立桌面应用或发布页面。

以项目和 Study 组织对话、输入、实验、证据与结论。同一个空间可切换“研究为主／对话为主”，保留选择与上下文。左侧为项目与研究资源；中部和右部根据工作姿态分配对话及研究画布；日志按需展开。具体布局仍可调整，以 PLAN.md 的待决定项为准。
