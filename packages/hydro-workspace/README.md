# 水文研究工作台

同一 dsh-hydrosystem 仓库内独立发布的配套 UI 插件，版本 0.1.0-alpha.7，目标为 DSH-Next 2.0.22-next／DSH 0.2.2-rc.1。基础能力包负责科学工具和托管环境，本包负责左侧“水文研究”入口、真实研究记录、动态任务画布及按需展开的右侧面板。尚未公开发布。

安装并重载后点击“水文研究”，选择基础能力包已创建的项目。画布读取 Study 0.2 的实际 activities 记录，默认聚焦率定、模拟、训练、评估与绘图任务，可切换全部活动记录。按产物引用或 trial_ref 建立已知依赖；没有证据的顺序不自动补线。运行状态来自活动记录，不凭文件存在判定计算成功。每次刷新只读原记录，不迁移或初始化 Study，不启动科学任务。

左侧统一管理概览、数据、实验、成果、研究记录和环境。研究助手独占中央主区域，切换管理页面时保留同一会话的原生输入草稿；文件、产物和实验使用 DSH 原生 Modal 临时查看，不挤压对话宽度；执行记录在底部按需展开。产物预览限制为当前研究已引用的文件，验证目录、大小与内容哈希。文件面板首版展示研究元数据与已引用产物，不是任意目录浏览器；终端首版为只读执行记录，交互式终端尚未接入。

研究助手由 DSH 原生 Conversation Factory 渲染，保留原模型、工具和输入组件。选择已有对话不自动修改研究绑定，执行前由水文专家核对项目。也可明确点击新建水文专家对话；这只创建 DSH 会话，不自动创建 Study 或计算。科学结果中的产物引用通过 DSH Session Projection 恢复到会话摘要；任务节点据此提供关联会话入口，子智能体会话使用 DSH 的父子地址打开。历史活动没有可确认关联会话时明确提示，不虚构子智能体对话。

默认读取当前 Profile 的 hydrosystem/projects。高级部署可配置绝对 stateRoot；maxRecords、maxPreviewBytes 和 refreshMs 控制只读列表、预览与刷新。首次安装的空工作台引导用户通过水文专家准备研究声明。API 使用宿主 Connection 的请求准入，卸载移除路由、侧栏入口、样式和组件；研究记录及基础环境保留。

任务、数据声明和部署位置以易读摘要呈现，路径、接口名、引用和原始记录收进“复现信息与原始记录”。任务页可以选中实验并进入研究对话；实验上下文由用户点击复制、粘贴到原生输入框并确认发送，界面不自动注入模型请求或修改会话研究绑定。研究记录页列出有真实科学引用依据的原对话，尚无独立笔记编辑器。
